# Submission Checklist

Before submitting:

- [ ] Run `npm install`
- [ ] Run `npm run dev`
- [ ] Test location permission Allow
- [ ] Test location permission Block
- [ ] Search a real place
- [ ] Select result
- [ ] Click Show Route
- [ ] Confirm road route appears
- [ ] Confirm distance and ETA appear
- [ ] Clear route
- [ ] Select a second destination without reload
- [ ] Test invalid search
- [ ] Test on mobile-width browser
- [ ] Run `npm run build`
- [ ] Verify `.env` is not committed
- [ ] Add screenshots to README
- [ ] Push repository to GitHub
- [ ] Deploy to Vercel/Netlify/GitHub Pages as appropriate
